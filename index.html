HOW TO ADD A PAGE

新しいページを追加する

4ステップで完了。git push するだけで自動デプロイ。

01

HTMLファイル作成

このディレクトリに newpage.html を作成。テンプレ不要、純粋なHTMLでOK。

02

一覧に追加

この index.html の #pagesGrid 内に <a class="page-card"> をコピペして追記。

03

コミット＆プッシュ

git add . && git commit -m "Add newpage" && git push でVercelが自動デプロイ。

04

公開完了

数十秒で https://your-project.vercel.app/newpage が公開。クリーンURL（.htmlなし）が自動付与。

# 新しいページを追加する一連の流れ git clone https://github.com/your-username/scratch-pages.git cd scratch-pages # 1. 新しいHTMLファイルを作成 echo '<h1>Hello</h1>' > newpage.html # 2. この index.html の #pagesGrid にカードを追加 code index.html # 3. コミット＆プッシュ → Vercelが自動デプロイ git add . && git commit -m "Add newpage" git push

mamacare（ママケア）

これだけでわかる！
デジタル化・AI導入補助金2026
申請マニュアル

IT導入支援事業者 登録手続きを、ゼロから丁寧に解説します

👤 このページは「ITに詳しくない方」向けです

📖 最初に読んでください

このマニュアルは、mamacare（ママケア）を「デジタル化・AI導入補助金2026」という国の補助金制度に登録するための手順書です。

mamacare を登録すると、産後ケア施設の方が mamacare を導入するときに、国の補助金を使って費用の一部（最大1/2〜2/3）をまかなえるようになります。

やることは以下の4ステップ。1つずつ進めていきましょう。

📋 やることリスト（4ステップ）

  1. gBizID（GビズID）を取得する
  2. SECURITY ACTION の宣言をする
  3. IT導入支援事業者として登録する
  4. ITツール（mamacare）を登録する
1

gBizID（GビズID）を取得する

⏰ 所要時間：書類なしなら即日、書類ありなら数日〜1ヶ月

gBizID（GビズID） は、国が運営する「ビジネス用のID」です。 このIDがないと、補助金の申請をするためのシステムにログインできません。

個人事業主の方は「gBizIDエントリー」という種類を選ぶと、審査なしですぐにIDを取得できます。

💡 大事なポイント
gBizIDには3種類あります。今回の申請では、どれを選んでも大丈夫です。
「エントリー」→ 審査なし、即日発行（おすすめ）
「プライム」→ 審査あり、数日〜1ヶ月。全部の機能が使える
「メンバー」→ プライムを持つ人の会社の社員用
① 下のリンクをクリックして、gBizIDのサイトを開いてください
https://gbiz-id.go.jp/
  1. サイトのトップページで「新規登録」をクリック
    画面の右上か中央に「新規登録」というボタンがあります
  2. アカウントの種類を選ぶ
    個人事業主の方は「エントリー」または「プライム」を選んでください。
    「エントリー」は入力したらすぐ使えます。「プライム」は身分証明書の提出が必要です。
  3. メールアドレスを入力する
    普段使っているメールアドレスを入力してください。後で確認のメールが届きます。
  4. メールに届いた認証コードを入力する
    届いたメールに書いてある番号（認証コード）を入力します。
  5. 必要事項を入力する
    名前、住所、電話番号などを入力します。個人事業主の場合は「屋号（やごう）」を聞かれるので「mamacare」と入力してください。
  6. 登録完了！
    エントリーの場合は、入力が終わったらすぐに使えるようになります。IDとパスワードは忘れないようにメモしておきましょう。
⚠️ 2026年7月からの変更点
· gBizIDのアカウントに「有効期限」ができました。定期的にマイページで更新が必要です。
· SMS（ショートメール）を使った認証が廃止されました。代わりに「gBizIDアプリ」または「メール認証」を使います。
· 書類を郵送する申請の場合、審査に最大1ヶ月かかります。オンライン申請がおすすめです。

📞 gBizIDの問い合わせ：0570-023-797（平日9:00〜17:00）

2

SECURITY ACTION の宣言をする

⏰ 所要時間：15〜30分（その日中に完了します）

SECURITY ACTION（セキュリティアクション）は、IPA（情報処理推進機構）という国の機関が運営している「うちの会社はセキュリティ対策をやってますよ」という宣言制度です。

補助金の申請には、この宣言をして「宣言ID」という番号を取得することが必須です。

🌟 おすすめは「二つ星（☆☆）」
今回の申請では「二つ星」での宣言が推奨されています。「一つ星」よりやることがちょっと増えますが、難しくないので安心してください。

必要なもの：

  • パソコンまたはスマートフォン
  • 会社（または事業）のプライバシーポリシーが載っているウェブサイトのURL
    → mamacare の場合は https://mamacare.jp/privacy があります
💡 二つ星と一つ星のちがい
「一つ星」：5つの約束ごとをチェックして宣言するだけ
「二つ星」：一つ星の内容に加えて「情報セキュリティ基本方針」という書類をウェブサイトに載せる必要があります
　→ mamacare は プライバシーポリシーに基本方針を含めているので、もう準備できています！
  1. IPAのSECURITY ACTIONサイトを開く
    https://www.ipa.go.jp/security/security-action/
    をクリックしてください。
  2. 「二つ星を宣言する」をクリック
    ページの中に「二つ星を宣言する」というボタンやリンクがあります。
  3. 情報を入力する
    会社名（または屋号）、連絡先などを入力します。
    · 屋号：mamacare
    · 代表者名：平田 亜紀子
    · ウェブサイトURL：https://mamacare.jp
    · プライバシーポリシーURL：https://mamacare.jp/privacy
  4. 二つ星の要件をチェックする
    画面に「うちはこういうセキュリティ対策をしていますか？」というチェックリストが表示されるので、該当するものにチェックを入れていきます。
    （mamacare は次の対策をしています：OSの更新、ウイルス対策、パスワード管理、重要情報のバックアップ、アクセス制御、暗号化など）
  5. 宣言内容を確認して送信
    入力した内容に間違いがないか確認して、「宣言する」ボタンをクリックします。
  6. 宣言IDが発行される
    登録が完了すると、宣言IDという番号が表示されます。
    🔑 例：SEC-J-XXXXXX-2026
    この番号は次のステップで使います。必ずメモしてください。
⚠️ 注意
宣言IDは補助金の申請画面で入力する必要があります。発行されたら忘れずに保存しておきましょう。
3

IT導入支援事業者として登録する

⏰ 所要時間：書類をそろえれば30分〜1時間 / 審査待ち：数週間

ここからが本番です。「IT導入支援事業者」としてmamacareを国に登録します。

この登録が通ると、mamacareが補助金の対象ツールとして正式に認められます。

📌 手順は「仮登録 → 本登録」の2段階
最初にサイトで仮登録をすると、登録したメールアドレスに「本登録の案内」が届きます。
it-shien.smrj.go.jp というアドレスからメールが届くので、「迷惑メール」に入っていないか確認してください。

事前に用意するもの：

  • ✅ 取得した gBizID（IDとパスワード）
  • ✅ 取得した SECURITY ACTION 宣言ID
  • ✅ 自分の住所や電話番号がわかるもの
  • ✅ 確定申告書（直近のもの。必要な場合があります）
  1. IT事業者ポータルを開く
    以下のURLをクリックしてください。
    https://console.it-shien.smrj.go.jp/IT-01/
    💡 これが2026年現在の正しいURLです。古い情報（portal.shinsei.it-shien...）は使えなくなっています。
  2. gBizIDでログインする
    ステップ1で取得したgBizIDのIDとパスワードを入力してログインします。
    個人事業主の場合は「屋号」を聞かれるので「mamacare」と入力してください。
  3. 仮登録の情報を入力する
    画面の案内に従って、次のような情報を入力します。
    屋号mamacare（ママケア）
    代表者氏名平田 亜紀子
    事業内容産後ケア施設向け予約・顧客管理SaaS提供
    形態個人事業主
    メールアドレスsupport@mamacare.jp
    所在地ご自身の住所
    電話番号ご自身の電話番号
    SECURITY ACTION宣言IDステップ2で取得した番号
    gBizIDステップ1で取得したID
  4. 提供する支援内容を入力する
    「この事業者としてどんなことを提供しますか？」という質問に答えます。次の内容を参考にしてください。
    • ITツールの導入支援（mamacareのセットアップのお手伝い）
    • 操作説明（使い方のレクチャー）
    • 継続的なサポート（メールでの質問対応）
  5. 仮登録完了メールを確認する
    入力が終わると、support@mamacare.jp にメールが届きます。メールの本文に「本登録を行うためのURL」が書いてあります。
    ⚠️ メールが届かない場合
    ・「迷惑メール」フォルダに入っていないか確認
    ・ it-shien.smrj.go.jp からのメールを受信できるよう設定
    ・それでも届かない場合は、もう一度最初からやり直してみてください
  6. 本登録を完了する
    メールに書いてあるURLをクリックして、本登録の画面に進みます。追加で聞かれる情報があれば入力してください。
  7. 審査を待つ（数週間）
    登録が完了したあとは、事務局の審査があります。通常数週間かかります。
    審査中はポータルサイトで状況を確認できます。
4

ITツール（mamacare）を登録する

⏰ 所要時間：1〜2時間 / 審査待ち：数週間

いよいよ最後のステップです。IT導入支援事業者としての登録が通ったら、実際に「mamacare」というツールを登録します。

📂 必要な書類はもう用意してあります
以下の資料は mamacare の docs/ フォルダにすでにあります。申請画面にコピペして使えます。
  1. ポータルサイトにログインする
    ステップ3で使ったIT事業者ポータルに、もう一度ログインします。
    https://console.it-shien.smrj.go.jp/IT-01/
  2. 「ITツールの登録」メニューを選ぶ
    画面上のメニューから「ITツールの登録」または「新規ツール登録」を探してクリックしてください。
  3. ツールの基本情報を入力する
    以下の情報を入力していきます。
    ツール名mamacare（ママケア）
    ツールURLhttps://mamacare.jp
    提供形態クラウド（SaaS）
    大分類Ⅰ 共通機能（顧客管理・予約・決済）と
    Ⅱ 業務特化型機能（産後ケアカルテ）の両方
    対象業種医療・福祉（産後ケア施設）
    対応OSiOS・Android・Windows・macOS（ブラウザ）
    言語日本語
  4. 機能説明を入力する
    「mamacareはどんなサービスですか？」という説明を300字程度で書きます。以下の内容を参考にしてください。
    ✏️ 機能説明のひな形（このまま使えます）
    「mamacare（ママケア）は、産後ケア施設向けの予約管理・顧客管理・ケア記録のクラウドプラットフォームです。電話・紙・Excelで分散していた産後ケア施設の業務（予約受付・顧客情報管理・スタッフ間の情報共有・決済処理）を、一つのシステムで完結させます。スタッフアカウントは無制限で、LINE通知やオンライン事前決済にも対応。直感的な操作性で、ITが苦手なスタッフでもすぐに使いこなせます。」
  5. 価格情報を入力する
    以下の情報を入力します。
    基本プラン月額6,000円（税別）
    初期費用0円（無料）
    最低利用期間なし（月次契約、縛りなし）
    補助対象となる費用ソフトウェア利用料（月額・年額）
  6. セキュリティ情報を入力する
    以下の3つのURLを入力します。
    • 利用規約 → https://mamacare.jp/terms
    • プライバシーポリシー → https://mamacare.jp/privacy
    • 特定商取引法に基づく表記 → https://mamacare.jp/tokushoho
  7. スクリーンショットを添付する
    以下の5つの画面の写真（キャプチャ）が必要です。
    • 予約カレンダーの画面
    • 顧客管理の画面
    • スタッフノートの画面
    • 管理ダッシュボードの画面
    • お客さま用の予約画面
    💡 まだスクリーンショットを撮っていなければ、ステージング環境（テスト用のサイト）にアクセスして画面をキャプチャしてください。PNGまたはJPG形式で保存します。
  8. 確認して送信する
    全部の項目を入力したら、内容に間違いがないかもう一度確認して「申請する」ボタンをクリックします。
🎉 これで申請完了です！
あとは事務局の審査が終わるのを待ちます。審査が通ると「ITツール番号」が発行されます。
この番号があれば、産後ケア施設の方が「mamacareを補助金で導入したい」と申請できるようになります。

✅ 審査が通ったらすること

  1. 1 ITツール番号を確認する — ポータルサイトにログインして、発行された番号をメモします
  2. 2 施設に案内を始める — 「mamacareは補助金の対象ツールです」と伝えられるようになります
  3. 3 施設の補助金申請をサポート — 必要書類の提供や、申請の手伝いをします
  4. 4 実績報告をする — 導入が終わったら、国に「これだけ導入しました」という報告をします
